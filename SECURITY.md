# Segurança / Security

Não publique cookies, tokens, arquivos de sessão, senhas ou chaves de assinatura em issues. O aplicativo desktop não usa cookies por padrão. `UIFOR_YTDLP_COOKIES` é uma escolha explícita do usuário; o arquivo permanece externo e nunca é recurso de build.

Para relatar uma vulnerabilidade que possa expor sessões ou arquivos, use o mecanismo privado de reporte do GitHub, quando disponível no repositório. Se ele não estiver habilitado, abra uma issue sem detalhes de exploração e solicite um canal privado. Não afirmamos oferecer um prazo de resposta ou uma auditoria de segurança completa.

English: never publish cookies, credentials or signing keys. Prefer GitHub private vulnerability reporting when available; otherwise request a private channel without posting sensitive details. A successful build or test suite is not a full security audit.
